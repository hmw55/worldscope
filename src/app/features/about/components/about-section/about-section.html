Explore the world through data.

WorldScope is an interactive global data explorer built to make country information, development indicators, and historical trends easier to understand.

Project Evolution

From coursework to WorldScope.

WorldScope began as a small undergraduate JavaScript programming project focused on using Angular to connect an interactive world map with country data. After completing the course, I returned to the concept and rebuilt it from the ground up as an independent portfolio project.

The new WorldScope expands that original idea with a redesigned interface, independent geographic data, country search, development indicators, historical visualizations, accessibility improvements, testing, and a more maintainable component architecture.

See how WorldScope evolved on GitHub →

Country and development data are provided by the World Bank. Geographic boundaries are derived from Natural Earth.
