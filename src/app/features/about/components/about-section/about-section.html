About

Explore the world through data.

WorldScope combines global statistics, geographic exploration, historical trends, and city-level context into a single interactive experience.

01

Interactive Global Data

Explore countries through an interactive world map, searchable country directory, demographic indicators, development metrics, and historical trends.

02

Country & City Context

Drill into major cities with population, coordinates, local time, timezone information, and current weather conditions for the selected location.

03

Modern Angular

Built with Angular, TypeScript, signals, RxJS, SVG and D3 geospatial tooling, with data from the World Bank, Natural Earth, and Open-Meteo.

Project Evolution

From Coursework Concept to Portfolio Application

WorldScope began as a smaller country-information concept created during my bachelor's coursework. I later rebuilt the idea independently from the ground up as a modern Angular application with a new architecture, new data sources, interactive mapping, historical visualization, search, city exploration, and live contextual data.

The current project focuses on frontend architecture, API integration, data visualization, accessibility, and combining multiple public datasets into a cohesive user experience.
